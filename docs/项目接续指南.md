## 1. 项目速览

- **定位**：Rust 版 Web 应用防火墙，对齐 C# `Pek.WAF`（规则引擎 + IP 名单 + UA 过滤 + 频率监控 + 日志），并按需求扩展爬虫分级与 GEO-AI 放行。
- **形态**：库 crate（`lib`），**不产出二进制**；宿主通过 `router.use_middleware(waf.middleware())` 一行接入。
- **技术栈**：Rust（edition 2024），依赖 `dhrust`(feature `net`) / `serde` / `serde_json`(preserve_order) / `regex`；dev-dependencies `bytes`。
- **远程仓库**：`main` 分支（GitHub 直连受限时按既有约定走 IP 直连）。

### 模块总览（`src/`）

| 文件 | 职责 |
|---|---|
| `lib.rs` | 对外入口：`Waf` / `WafConfig`、模块组织、接入示例 |
| `config.rs` | 配置模型与 `Config/Waf.json` 读写（首启生成、mtime 节流热重载） |
| `middleware.rs` | dhrust 中间件实现：请求检查、响应观察、回环豁免 |
| `attack.rs` | SQLi / XSS / 路径穿越等攻击特征（URL 解码后检测） |
| `bots.rs` | 爬虫分级：放行搜索引擎与 GEO-AI 抓取器，拦截恶意爬虫/扫描器 |
| `ratelimit.rs` | CC 防护：按 IP 固定窗口限速（白名单爬虫不受限；引擎复用 `dhrust::ratelimit`） |
| `throttle.rs` | 接口级限流（对齐 C# `DH.RateLimter`）：七种策略、多阀门优先级、`WhenNull`、429 多格式、`Config/Throttle.toml` 热重载、可注入 Redis 计数 |
| `rules.rs` | 自定义 JSON 规则集（与 C# Pek.WAF Ruleset 格式兼容，新增 `IsBotKind`） |
| `wafreq.rs` | 请求抽象（供规则引擎与各检测器复用） |

## 2. 常用命令（构建 / 测试 / 回归）

```powershell
cargo check                       # 写代码时的秒级校验
cargo build --profile fast        # 本机日常编译/调测（无 LTO，快）
cargo test                        # 回归：49 个单元测试（各模块内）+ 2 个集成测试（1 ignored）
cargo clippy --all-targets -- -D warnings   # 零告警门禁
cargo build --release             # 发版档（thin LTO + strip）
cargo build --release --target x86_64-unknown-linux-musl   # 需 cargo-zigbuild（宿主交付走 zig）
```

> 依赖下载走 `.cargo/config.toml` 的 rsproxy 镜像（与生态各仓一致）；若报「no matching package」，先确认该文件存在再 `cargo fetch`。
