## 2026-10-25（二）· 限流能力全面审计与整改

**用户原话**：「目前有做全面审计么？」

**审计范围**：`Pek.RWaf::throttle` + `DH.RustBase::ratelimit` + RWaf CC 接入 + 六个消费方编译回归；对照 C# `DH.RateLimter` 逐项核对。

**结论**：未发现 P0 阻断问题；修复 2 类 P1 + 4 项 P2：
1. **P1** `FixedWindowStore` 分片满时 O(n) `retain`+`min_by_key` → 改为 **O(1)** 任意键淘汰（唯一键攻击下不再形成 CPU 热点）；
2. **P1** 热路径重复分配（路径小写、`{param}` Vec、每阀门 API 名、无条件 IP 转换、重复配置快照）→ 全部消除/按需化；
3. **P2** Query/Form 键名改大小写不敏感（先精确后兜底）；
4. **P2** 空白策略值按 C# `IsNullOrWhiteSpace` 省略计数键值段；
5. **P2** `ThrottleConfig` 加载即按 priority 归一化，配置往返顺序一致；
6. **P2** `guard` 规则改 `Arc` 共享，消除每请求深拷贝；
7. **P2** 配置迁移/补齐/修正提示写入日志；重载时文件被删除后的 mtime 刷新。

**确认项**：WAF CC 窗口从自然分钟改为「每 key 首次命中起 60 秒」→ 预期变化，文档同步；
`Retry-After` 仍为 60（上界），新增 `RateLimiter::check` 返回 `Decision` 供宿主取精确 `reset_in`。

**验证**：dhrust **303 passed / 1 ignored**、clippy 零告警；RWaf **55 lib + 2 集成（1 ignored）**、clippy 零告警；
Linux x64/arm64 musl `cargo check` 通过；六个消费方 `cargo check` 通过。

**完整报告**：`docs/审计报告-限流能力-2026-10-25.md`。

## 2026-10-25 · 接口级限流合入（对齐 C# DH.RateLimter，不新建独立库）

**用户原话**：「帮我参考 G:\Code\Pek.FrameWork\DH.RateLimter 实现 Rust 版本的，而且也要参考其他项目实现全局用户指令相关。同时也要考虑 DH.RustBase 方法提取和复用，先考虑有没有必要把这个限流的项目和 Pek.RWAF 项目中，就不用另外再实现一个单独的限流库了」（用户当时不可选，授权按推荐方案自主决定）

**背景**：C# `DH.RateLimter` 是 MVC 特性驱动的**接口级多策略限流**（`[RateValve]` 可多个、七种 `Policy`、`WhenNull`、按 Action 计数）；`Pek.RWaf` 已有的是**全站每 IP** 的 CC 限流，两者定位不同但同属 Web 防护，且计数机制重复。

**决定**：
1. **不新建独立限流库**（`Pek.RRateLimter` 空仓不使用）——HTTP 接口级限流合入 `Pek.RWaf` 新增 `throttle` 模块；
2. **通用固定窗口计数下沉 `dhrust::ratelimit`**：`CounterStore` 抽象 + `WindowLimiter` + 分片进程内 `FixedWindowStore`（首次创建过期、窗口内不续期、正好放行 `limit` 次、分片上限防内存膨胀），未来可注入 `Pek.RRedis` 实现共享计数；
3. RWaf 自身 CC 限流（`ratelimit.rs`）改为薄封装 `WindowLimiter`，**同一 crate 不再有两套限流实现**；
4. 复用 `dhrust` 既有能力：`sign::md5_hex/md5_short`、`net::ip_to_num`（新增，对齐 C# `IpToNum`）、`net::panel_auth::client_ip`、`config::TomlConfig`、`logs`、`net::http::{DGResult, state}`；
5. C# 的 5 分钟 MD5/IP 缓存**有意不做**：Rust 单次计算百纳秒级，避免无界缓存；C# 的黑白名单本就未实现，IP 名单继续由 WAF 负责。

**C# → Rust 映射**：
- `[RateValve]` 特性 → `ThrottleRule.valves`（TOML 规则表或 `Throttle::guard`）；
- `Policy` 七种同名；`WhenNull.Pass/Intercept` 同名；`Limit/Duration` → `limit/duration`（秒）；
- `IRateLimitStore.IncrementAsync` → `dhrust::ratelimit::CounterStore`；
- `ReturnType` 三种 → `ThrottleReturnType`；`Api-Throttle-Status` 同名请求头（并回写响应头）；超限 `429` + `Retry-After`；
- `RateLimterOptions` 三个钩子 → `set_user_identity` / `set_client_ip` / `set_limited_response`。

**新增文件/接口**：
- `Pek.RWaf/src/throttle.rs`：`Throttle` / `ThrottleConfig` / `ThrottleRule` / `RateValve` / `Policy` / `WhenNull` / `ThrottleReturnType` / `LimitInfo` / `ThrottleVerdict`；`Config/Throttle.toml` 首启生成、10 秒 mtime 热重载、旧 `Throttle.json` 自动迁移。
- `DH.RustBase/src/ratelimit.rs`：`CounterStore` / `WindowLimiter` / `FixedWindowStore` / `Decision` / `CounterHit`。
- `DH.RustBase/src/net/mod.rs::ip_to_num`、`sign/mod.rs::md5_short`。

**验证**：
- `DH.RustBase`：`cargo test` **303 passed / 1 ignored**；`cargo clippy --all-targets -- -D warnings` 零告警。
- `Pek.RWaf`：`cargo test` **49 lib + 2 集成（1 ignored）**全绿；`cargo clippy --all-targets -- -D warnings` 零告警。
- 新增 throttle 单测覆盖：IP 隔离、方法/路径匹配（精确/前缀/`{param}`）、`WhenNull` 两种、多阀门优先级、Query/Cookie/Form/Path/User 策略、三种响应格式与 `Retry-After`、配置往返与热重载、`apply_config` 清计数、全局开关、中间件端到端、`guard` 端到端。

**遗留/后续**：
1. 消费方（`Pek.RPanlServer`、`HLZX.EIP`）本次只增 API + 内部重构，命令面不变；下次打包自动生效，需跑一次 `cargo check` 确认。
2. 如需多实例全局限流，实现 `CounterStore` 的 Redis 版本（Pek.RRedis）并通过 `Throttle::with_store` / `load_with_store` 注入；`Retry-After` 由存储实现给出 `reset_in`。
3. `Form` 策略目前只支持 urlencoded（`Ctx` 已有解析）；multipart 待 `dhrust` 路由层支持后再接。

## 2026-10-23 · WAF 配置改 TOML（`Config/Waf.json` → `Config/Waf.toml`，含自动迁移）

**用户原话**：「我要所有这些使用Json都换掉，且要做迁移」「都不考虑复用DH.RustBase的方法嘛」

**决定**：
1. 配置文件改 **TOML**（可写注释），路径常量 `CONFIG_REL = "Config/Waf.toml"`、
   `LEGACY_CONFIG_REL = "Config/Waf.json"`；旧文件首次加载自动迁移为 TOML 并备份为 `.json.bak`。
2. **不再自实现配置管线**：解析/补齐/容错/原子写委托 `dhrust::config::TomlConfig<T>`（`Config<T>` 的 TOML 版，
   `feature = "toml"`）；本库只提供「带注释模板 + 结构体」。
3. **迁移合并口径**：旧 JSON 必须按**原始 JSON** 与调用方预设合并（现由 `dhrust::config::TomlConfig` 自动完成：模板=预设、旧值覆盖），
   否则先反序列化成 `WafConfig` 会把缺失键填成结构体默认值，把 `public_site` 预设覆盖掉（已踩到并修正）。
4. `Waf::load_with_default` 首次启动：旧 JSON 存在则迁移；否则按预设生成 TOML。

**验证**：`cargo test` **35 项**全绿（新增规则集 TOML 往返、旧 JSON 迁移、预设继承、加载入口迁移）。
