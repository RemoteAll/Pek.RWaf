# 用户档案（Pek.RWaf 定制部分）

> 通用偏好见用户级《跨项目接续协议》（本机 `%APPDATA%\Code\User\prompts\跨项目接续协议.instructions.md`）；本文件只记录与本项目直接相关的用户口径。

## 已确认口径（含用户原话）

1. 「Pek.RWaf 首版：爬虫分级（放行搜索引擎/GEO-AI）+ SQLi/XSS/路径检测 + CC 限速 + C# Pek.WAF 兼容规则引擎」—— 功能边界以此为准。
2. **规则文件与 C# 端互通**：同一份 `Ruleset` JSON 双端共用，Rust 侧只做加法（`IsBotKind`），不改既有操作符语义。
3. **回环地址默认豁免**（`127.0.0.1` / `::1`），避免本机 curl 联调被误拦；生产放开由宿主配置决定。
4. **网络层实测必须带浏览器 UA**：裸 `curl` 会被恶意爬虫规则拦截——这是预期行为，不是 bug。
5. **限流能力不单独建库**：「帮我参考 G:\Code\Pek.FrameWork\DH.RateLimter 实现 Rust 版本的……先考虑有没有必要把这个限流的项目和 Pek.RWAF 项目中，就不用另外再实现一个单独的限流库了」——已决定合入 `Pek.RWaf`（`throttle` 模块），通用计数引擎下沉 `dhrust::ratelimit`。
